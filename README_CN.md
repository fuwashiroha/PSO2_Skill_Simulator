# PSO2 Skill Simulator
<img width="2191" height="1838" alt="image" src="https://github.com/user-attachments/assets/e5830e18-c546-4bf6-841f-233179fc4fa5" />

支持旧《PSO2》全部13个职业的天赋加点模拟器，包含技能图标，支持中日切换和离线使用。

## 使用说明

1. 下载并完整解压文件，用浏览器打开 `index.html`。
2. 选择主副职业，设置职业等级和追加SP。
3. 点击技能等级加点，`M` 加满，右键减少1级；所需前置技能会自动补齐。
4. 点击技能名称，查看效果说明和各级数值。

配点会自动保存在当前浏览器。首次使用时载入各主职业的默认方案，已有存档则优先恢复存档。“恢复截图配点”可恢复默认方案，“重置当前树”可清空手动配点。右上角按钮可切换显示语言。

※ 离线版配点链接包含本地文件路径，换电脑或移动文件后可能无法直接使用。
