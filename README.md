# PSO2 Skill Simulator

旧『PSO2』の全13クラスに対応した、スキルアイコン付きのスキルシミュレーター。日本語・中国語の切り替えとオフライン利用に対応しています。

## 使い方

1. ファイル一式をダウンロード・展開し、`index.html` をブラウザーで開きます。
2. メイン・サブクラス、クラスレベル、追加SPを設定します。
3. スキルの数字でレベルを指定します。`M` で最大、右クリックで1レベル減らせます。必要な前提スキルは自動で取得されます。
4. スキル名をクリックすると、効果と各レベルの数値を確認できます。

配分はブラウザーに自動保存されます。初回は各メインクラスの既定の配分を読み込み、保存済みの配分がある場合はそちらを優先します。「画像の配分に戻す」で既定の配分を復元、「現在のツリーをリセット」で手動の配分を消去できます。右上のボタンで表示言語を切り替えられます。

※ オフライン版の構成リンクにはローカルのファイルパスが含まれます。別の端末・保存場所では、そのまま利用できない場合があります。
